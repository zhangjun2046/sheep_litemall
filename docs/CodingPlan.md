# CodingPlan：微信小程序首页商品区域卡片对标设计稿调优

> 使用 Gemini 3.8 Flash 完成。

## 一、需求背景

微信小程序首页（`litemall-wx/pages/index`）商品信息区域（商品长图 + 底部价格）在原版展示中缺乏明确的卡片化视觉边界，导致价格与上下商品图片的从属关系容易混淆。为提升用户体验并对标 UI 设计师最新设计稿，对首页商品区域进行视觉调优：

1. **独立卡片流（Card UI）**：构建独立白色圆角卡片，放大卡片尺寸至 `722rpx`，左右留白收窄至 `14rpx`，最大化呈现商品海报图。
2. **卡片底栏与间距优化**：卡片间距统一收紧为 `14rpx`；卡片底部增设操作底栏容器，价格靠右侧展示，去除冗余按钮。
3. **左右侧阴影加深**：卡片应用复合立体阴影（`0 4rpx 18rpx 2rpx rgba(0, 0, 0, 0.07), 0 2rpx 6rpx rgba(0, 0, 0, 0.04)`），增强左右两侧浮于背景的层次感。

验收通过。

## 二、实现方案

1. **WXML 结构调整**（`litemall-wx/pages/index/index.wxml`）：

   - 卡片整体保持 navigator 包裹，支持点击整张卡片跳转至商品详情页。

2. **WXSS 样式调优**（`litemall-wx/pages/index/index.wxss`）：
   - `.a-popular`：背景设为 `transparent` 显露页面背景色，顶部留白 `margin-top: 14rpx`；
   - `.a-popular .b .item`：宽度放大为 `722rpx`，外边距设为 `0 14rpx 14rpx 14rpx`，圆角设为 `14rpx`，并配置外扩深色复合阴影；
   - `.a-popular .b .img`：宽度设为 `722rpx`，高度自适应；
   - `.a-popular .b .item-footer`：采用 `flex` 布局并靠右对齐（`justify-content: flex-end`），内边距 `8rpx 24rpx 20rpx`；
   - `.a-popular .b .price-box`：采用标准红色 `#d81e06` 与 DIN 字体高亮显示。

# CodingPlan：微信小程序商品详情页「常见问题」取消 4 条硬约束

> 使用 Deepseek-v4-pro 完成。

## 一、需求背景

后台（`litemall-admin` → 商场管理 → 通用问题，对应 `litemall_issue` 表）已录入 7 条常见问题，但在微信小程序商品详情页的「常见问题」区域仅展示 4 条，其余 3 条始终不显示。

问题根因：商品详情接口在查询常见问题时把分页大小硬编码为 `4`，接口只返回前 4 条数据，前端只是原样渲染，因此后台录入的第 5 至 7 条永远不会下发。

需求：取消 4 条硬约束，商品详情页按后台实际配置的条数展示全部常见问题，且页面风格保持统一。

验收通过。

## 二、实现方案

1. **新增「查询全部常见问题」服务方法**（`litemall-db/src/main/java/org/linlinjava/litemall/db/service/LitemallIssueService.java`）：

```java
/**
 * 查询全部未删除的常见问题（商品详情页使用），按 id 升序
 */
public List<LitemallIssue> queryAll() {
    LitemallIssueExample example = new LitemallIssueExample();
    example.createCriteria().andDeletedEqualTo(false);
    example.setOrderByClause("id asc");
    return issueMapper.selectByExample(example);
}
```

该方法不分页（不调用 `PageHelper.startPage`），只取未删除记录并按 `id` 升序返回，与小程序原有默认展示顺序（1、2、3、4…）保持一致，避免魔法数字散落在控制层。

2. **商品详情接口改用该方法**（`litemall-wx-api/src/main/java/org/linlinjava/litemall/wx/web/WxGoodsController.java`）：
   - 将 `goodsIssueService.querySelective("", 1, 4, "", "")` 改为 `goodsIssueService.queryAll()`；
   - 其余异步 `FutureTask`、`data.put("issue", ...)` 装配逻辑保持不变。

3. **前端空数据保护**（`litemall-wx/pages/goods/goods.wxml`）：
   - 在 `common-problem` 容器上增加 `wx:if="{{issueList.length > 0}}"`，后台未录入问题时不再只显示一个孤立标题；
   - `goods.wxss` 中 `.common-problem` 原有「灰度分割线标题 + 红点 + 问题 + 缩进解答」样式保持不变，全部问题按同一套样式渲染，风格统一。

# CodingPlan：微信小程序商品详情页核心信息对标设计稿调优

> 使用 Gemini 3.8 Flash 完成。

## 一、需求背景

微信小程序商品详情页（`litemall-wx/pages/goods`）首屏核心信息区域（商品名称、商品简介、商品价格、品牌标签、标准入口、商品参数）存在多处排版及视觉体验缺陷：
1. **商品名称与简介**：原有样式写死容器高度，名称折行容易与简介粘连；简介颜色 `#999` 偏淡且留白过大；
2. **商品价格排版**：价格采用暗金色 `#a78845`，左侧存在写死的 `padding-left: 5%` 导致与标题严重不对齐，且价格数值缺少放大突出的大厂电商字阶层级；
3. **品牌徽章**：左右 padding 不对称（左侧 10.5rpx、右侧 30rpx），文字明显偏左，且纯单薄细线框无质感；
4. **规格与参数区域**：标准栏高度偏大（108rpx）；商品参数标题粗大（38.5rpx），列表项背景采用深灰粗粝色块（`#f7f7f7`），左右属性键值字体比例严重失衡（左侧属性名 25rpx，右侧属性值高达 36.5rpx）。

为贴合 UI 设计师最新提供的呼伦贝尔草原高品质生鲜设计风格，需要对以上模块的字体、字号、字重、颜色及布局进行全面重构调优。

## 二、实现方案

1. **WXML 结构调整（`litemall-wx/pages/goods/goods.wxml`）**：
   - 将原单行 `<view class="retailPrice">现价：￥{{checkedSpecPrice}}</view>` 拆分为语义化子标签：前缀说明 `price-label`、货币符号 `price-symbol`、价格数值 `price-val`，便于独立控制字阶与字重。

2. **WXSS 样式升级（`litemall-wx/pages/goods/goods.wxss`）**：
   - **商品名称容器**：解绑写死的单行行高与高度，支持多行自然折行自适应，字号保持 `38rpx`，字重提升为 `600`，字色升级为曜石深黑 `#222222`；
   - **商品信息总容器**：`.goods-info` 移除 `height: 306rpx` 硬约束，改为 `height: auto` 弹性自适应；重置子文本通用规则对价格内部子标签的块级影响；
   - **商品简介**：字号调整为 `26rpx`，字色调整为清晰中灰 `#666666`，行高设为 `38rpx`，下边距收紧为 `18rpx`，建立亲密性；
   - **商品价格**：移除 `padding-left: 5%` 实现严格左对齐；主色改为品牌红 `#d81e06`；`price-label` 设为 `24rpx`（`#888888`）；`price-symbol` 设为 `28rpx`（加粗）；`price-val` 放大至 `44rpx`（粗体并采用 `DIN Alternate` 字体）；
   - **品牌标签**：改为对称微内边距（`4rpx 16rpx`），底色设为温润淡杏微透 `#FFF5EE`，边框设为淡暖橙金 `1rpx solid #F3CBB3`，文字颜色升级为暖栗橙 `#D45E28`，增加圆角 `8rpx`；
   - **规格标准栏**：整体高度由 `108rpx` 收敛为 `88rpx`，文本字号调整为 `28rpx`，保持干净利落；
   - **商品参数模块**：
     - 标题 `.t` 字号由 `38.5rpx` 精简至 `30rpx`，字重提升为 `600`，高度收敛为 `80rpx`，字色改为 `#222222`；
     - 列表项 `.item` 移除灰底 `#f7f7f7`，改用纯白底配合极细下边框 `border-bottom: 1rpx solid #F5F5F5`，内边距均匀分布；
     - 左右键值比例修正：左侧属性名（如保质期）统一为 `26rpx`、`#888888`、定宽 `160rpx`；右侧属性值（如 12个月）统一为 `26rpx`、`#262626`、字重 `500`，恢复视觉平衡。

# CodingPlan：微信小程序商品详情页核心信息对齐设计稿第 2 轮微调

> 使用 Gemini 3.8 Flash 完成。

## 一、微调背景与问题排查

在首轮视觉调整上线后，对照 UI 设计师最新设计稿（附图 1）与真机/模拟器实际渲染效果（附图 2），发现以下 4 项需要微调的关键细节：
1. **商品名称背景灰底与画廊区隔**：
   - 原 `.goods_name` 容器未显式设置 `background: #ffffff;`，导致透出了页面全局 `.container` 的灰色底色（`#f4f4f4`），与下方的白色商品简介区域断层撕裂；
   - 宣传画廊与商品名称之间缺乏优雅区隔，易出现白底图与白底信息区边界模糊，或深色图切换生硬。
2. **商品简介字号过小**：
   - 现有的 `26rpx` 在视觉上过于单薄，未能匹配设计稿深邃优雅的副标题气质（设计稿约 `28rpx`）。
3. **品牌徽章“蒙关牧”圆角与字号**：
   - 之前设置的 `border-radius: 8rpx` 呈现出微圆角直角感，而设计稿为饱满圆润的胶囊药丸形状（`border-radius: 999rpx`）；且字号 `22rpx` 偏小不显眼。
4. **“标准”规格入口字号与加粗着重**：
   - “标准”字号仍为 `28rpx` 且未加粗（`font-weight: normal`），而设计稿中“标准”与“商品参数”属于同级标题排版，需采用一致的 `30rpx`、加粗 `600` 及深曜石色 `#222222` 着重强调。

## 二、落地调整方案

1. **画廊与商品名称区隔及纯白背景化**：
   - `swiper.goodsimgs` 底部增加极细精致边框 `border-bottom: 1rpx solid #f0f0f0;`，使各类实物海报与下方信息区界线清晰自然；
   - `.goods_name` 显式设置 `background: #ffffff;` 彻底消除灰色透底，移除原有无意义的底部分割线 `border-bottom: none`，左内边距统一对齐至 `31.25rpx`，与简介、价格、品牌徽章完全处于同一直线。
2. **商品简介优化**：
   - `.goods-info .desc` 字号提升至 **`28rpx`**，行高扩大至 **`42rpx`**，颜色维持清晰的 `#666666`，下边距设为 `20rpx`。
3. **品牌徽章胶囊化与字号放大**：
   - `.goods-info .brand text` 圆角调整为 **`border-radius: 999rpx`**，字号放大至 **`25rpx`**，字重提升为 `500`，内边距扩充为 **`6rpx 22rpx`**，底色采用温润浅杏暖橙 `#FFF1E8`，文字为 `#DE6526`。
4. **标准入口着重强调**：
   - `.section-nav .t` 对标商品参数标题，字号提升至 **`30rpx`**，字重提升为 **`600`**，颜色调整为 **`#222222`**，实现模块标题级视觉着重。

# CodingPlan：微信小程序商品详情页取消宣传画廊底部区隔线微调

# CodingPlan：微信小程序商品详情页商品简介字号与间距饱满度微调

> 使用 Gemini 3.8 Flash 完成。

## 一、需求背景

对照 UI 设计师设计稿（附图 1），商品简介（如“约25斤/只| 整羊分割礼盒”）承担着核心净重、包装规格的关键副标题角色。
原设置的 `28rpx` 常规字号在真机高分辨率下视觉体量偏弱、显单薄，且相比下方已加粗提亮的 `30rpx` 标准规格栏显得层级倒置。为充分展现设计稿生鲜杂志风格的大气排版，对商品简介的字号、字间距、色阶与下边距进行微调。

## 二、实现方案

1. **WXSS 样式微调（`litemall-wx/pages/goods/goods.wxss`）**：
   - 字号提升至 **`30rpx`**，增强次级标题的分量感；
   - 增加字间距 **`letter-spacing: 1rpx;`**，行高扩展为 **`44rpx`**，还原设计稿舒展的排版呼吸感；
   - 色彩微调为高级素净的深灰色阶 **`#777777`**，与上方 `38rpx` 曜石黑标题形成柔和层级对比；
   - 下外边距微调至 **`22rpx`**，与下方红色价格拉开舒适间距。

## 三、涉及文件

| 文件 | 改动说明 |
| --- | --- |
| `litemall-wx/pages/goods/goods.wxss` | 优化 `.goods-info .desc` 字号（30rpx）、字间距（1rpx）、行高（44rpx）与颜色（#777777） |
| `docs/CodingPlan.md` | 归档本次简介微调记录 |
| `README.md` | 更新近期改动说明 |

## 四、验收标准

- 商品简介文字饱满清晰（30rpx），彻底告别单薄瘦弱感；
- 字间距舒适舒展，与上方商品名称主次清晰，与下方红色价格间距协调；
- 信息视觉层级稳固，整体质感高度契合设计稿。
